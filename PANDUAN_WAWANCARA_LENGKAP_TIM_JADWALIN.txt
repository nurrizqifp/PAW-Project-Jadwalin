1. KONTRIBUSI NYATA
Pertanyaan:
"Apa saja kontribusi teknis utamamu di proyek Jadwalin?"

Jawaban:
"Fokus utama saya adalah membangun mesin penjadwalan cerdas (AI Solver Core) dan validator kendala:
a. Integrasi Google Gemini API (services/aiSolverService.js):
   - Merancang prompt engineering deterministik berbasis aturan PRD dengan format luaran JSON ketat (responseMimeType: application/json) dan suhu rendah (temperature: 0.1).
b. Deterministic Fallback Solver (Greedy Constraint Satisfaction Problem / CSP):
   - Membangun algoritma cadangan lokal jika API key Gemini tidak tersedia atau limit kuota habis.
   - Menerapkan heuristik MRV (Most Constrained Variable First): memprioritaskan mata kuliah praktikum lab dan dosen dengan jam mengajar terbanyak.
   - Menerapkan load balancing beban hari kerja (Senin-Sabtu) agar jadwal tidak menumpuk di hari Senin-Selasa saja.
c. Validasi Hard & Soft Constraints Post-Generate:
   - Validasi HC-01 (Zero clash dosen), HC-02 (Zero clash ruangan), HC-03 (Jeda ibadah Dhuhur & Ashar), HC-04 (Alokasi Ruang Kuliah Besar untuk kelas gabungan), dan Lab Matching 100%.
   - Menghitung metrik keberhasilan PRD (M-01 sampai M-04)."

2. ALUR WEB YANG DIKELOLA
Pertanyaan:
"Bagaimana alur dari saat admin menekan tombol Generate sampai jadwal keluar?"

Jawaban:
"1. Admin menekan tombol Generate di /admin/generate.
2. Endpoint POST /api/generate menerima permintaan.
3. Sistem mengumpulkan snapshot data master: dosen (beserta preferensi waktu dan hari off), ruangan (tipe dan kapasitas), serta mata kuliah (SKS, jenis, kelas).
4. Payload dikirim ke callGeminiApi(). Jika gagal atau offline, dialihkan ke solveDeterministicFallback().
5. Hasil jadwal divalidasi oleh validateGeneratedSchedule().
6. Jadwal yang valid disinkronkan ke PostgreSQL melalui syncScheduleToDatabase() dan disimpan di memori JadwalModel.
7. Laporan konflik, durasi generate, dan persentase kepuasan preferensi dikembalikan ke antarmuka admin."
